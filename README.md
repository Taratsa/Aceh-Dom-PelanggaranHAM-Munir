# Aceh, DOM dan Pelanggaran HAM — EPUB source

Tulisan Munir Said Thalib, Jakarta, 19 April 1999, dibuat dari pindaian PDF (OCR via TurboOCR).

## Build

`book.md` is the hand-edited source (`book.json` `"source": "book.md"`). Edit it directly; it is never regenerated.

    cd /Users/sf/Documents/workspaces/pdf-to-epub-turboocr
    python3 pipeline.py "<path to this folder>" --steps build,verify,se

Do not run the `ocr` or `images` steps for this book.

## Outputs

- `Aceh, DOM dan Pelanggaran HAM - Munir.epub`: pandoc build
- `Aceh, DOM dan Pelanggaran HAM - Munir (SE).epub`: Standard Ebooks manual edition (`--steps se`), Indonesian, white-label
- `verify.json`, `review.txt`: build checks
- `se-src/`, `se-out/`: Standard Ebooks source tree and build output of the SE edition (regenerated by `--steps se`)

## Hand-editable files

- `book.md`: all text
- `metadata.yaml`: EPUB metadata (publisher, producer, creator, rights, pinned identifier) for both editions
- `se-imprint.md`, `se-colophon.md`, `se-license.md`: Keterangan Edisi, Kolofon and Lisensi pages of the SE edition

## Lineage OCR -> book.md

`ocr/md/pNN.md` (raw OCR, regenerable from the PDF, not tracked) -> `book.ocr-original.md` (frozen baseline; the rotated margin text, the library stamp and the printed-title duplicate are already removed, and one page-split paragraph is joined) -> `book.md`.
`corrections.json` logs every spelling correction from the baseline to `book.md` (SymSpell and manual edits, with the words kept as printed) and is written by `corrections.py` only.
`python3 corrections.py check <this folder> --scan` replays it and must pass.
The corrections were not compared against the scan images; they rest on SymSpell suggestions, the dictionaries and sentence context. The author's own spelling (e.g. `intrumen`, `berekpresi`, `tehnis`) is kept as printed.

## Metadata notes

`dc:source` is the catalog page https://pustaka.taratsa.id/book/330/ (digitalisation from KontraS), in both editions (`metadata.yaml` `source`, `book.json` `se.sources`).
The imprint, colophon and license pages (`se-imprint.md`, `se-colophon.md`, `se-license.md`) follow the wording of the Marsinah edition (github.com/Taratsa/Kekerasan-Penyidikan-Dalam-Kasus-Marsinah); only title, author, source phrase and release date differ.
LCSH subjects were taken from id.loc.gov and have not been reviewed by an editor.
Three Indonesian subjects (Hak asasi manusia, Hubungan sipil-militer, Daerah operasi militer) are free text with no authority ID: the terms appear in Perpusnas's Daftar Tajuk Subjek (2002-2010 cumulation), but their preferred forms were not checked against the current edition or tajukonline.perpusnas.go.id.
